Ноги, ягодицы, кор, тазовое дно и выносливость

Поставь fit как приложение — иконка на экране, работает без интернета.

Чтобы работало без интернета: меню браузера ⋮ → «Добавить на главный экран».

Как пользоваться (прочитай один раз)
  1. Тренировки идут по кругу: A → B → C → A… Страница помнит, какая следующая. Пропустил неделю — просто делай следующую по кругу.
  2. Выбери Зал или Дом. Упражнения сверху вниз, по порядку.
  3. «3 × 8–12» = 3 подхода, в каждом 8–12 повторов. Вес подбирай так, чтобы в конце подхода оставалось ещё 2 повтора в запасе.
  4. У каждого подхода кнопки −/+ для веса и повторов. Сделал подход — жми ✓, внизу запустится таймер отдыха. Вес и повторы подставляются из прошлого раза, а подсказка говорит, когда прибавить.
  5. В конце нажми «Сохранить тренировку». Без интернета тоже можно: отчёт уйдёт сам, когда появится сеть. Кегель и вело-интервалы записываются сами, когда таймер дошёл до конца.
  6. На часах запусти тренировку «Силовая» (или «Велотренажёр») — так пульс попадёт в Zepp.

    Тазовое дно (Кегель)

    Что за мышца: та, которой останавливаешь струю мочи и подтягиваешь основание члена вверх. Проверь один раз, тренироваться на унитазе не надо.

    Как: лёг, ноги согнуты. Сжал эту мышцу и держишь, пока горит «Сжать». Пресс, ягодицы и бёдра расслаблены, дыхание ровное. На «Расслабить» отпускаешь полностью. Каждый день, около 8 минут.

    Ключ доставки отчётов

    С ключом отчёты сами уходят в твой приватный репозиторий fit-log, а Claude забирает их оттуда. Ключ хранится только на этом телефоне.

    Как получить ключ (3 минуты, один раз)
    1. Открой github.com → новый fine-grained token (войди в kireev-duty).
    2. Token name: fit-phone, Expiration: 1 год.
    3. Repository access: Only select repositories → fit-log.
    4. Permissions → Repository → Contents: Read and write. Остальное не трогай.
    5. Generate token → скопируй → вставь ниже → «Сохранить ключ» → «Проверить доставку».
